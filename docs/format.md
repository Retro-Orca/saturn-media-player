# SVT1形式

すべての数値はビッグエンディアンです
ファイルの先頭は2048バイトのヘッダー、その後は55,296バイトの独立したグループです
1グループは12フレーム、音声4410サンプルを持ち、CDの27セクターに一致します

## ファイルヘッダー

| オフセット | バイト数 | 値 |
| --- | --- | --- |
| 0 | 4 | ASCII `SVT1` |
| 4 | 4 | バージョン1 |
| 8 | 4 | 幅320 |
| 12 | 4 | 高さ224 |
| 16 | 4 | 実フレーム数 |
| 20 | 4 | グループ数 |
| 24 | 4 | 1グループ12フレーム |
| 28 | 4 | 1グループ27セクター |
| 32 | 4 | 音声サンプルレート22050 |
| 36 | 4 | 1グループ4410サンプル |

残りは0です

## グループ

| オフセット | バイト数 | 内容 |
| --- | --- | --- |
| 0 | 32768 | 8×8 RGB555画像256枚 |
| 32768 | 13440 | 12フレームのタイル番号 |
| 46208 | 8820 | 符号付き16ビットのモノラルPCM |
| 55028 | 268 | セクター境界までの0埋め |

画像は各画素2バイト、上から下、左から右の順です
画素は `0x8000 | R | G<<5 | B<<10` で、各成分は5ビットです
タイル番号は1バイト、各フレーム40列×28行の1120個です
フレーム間の差分を使わないので、任意のグループから再開できます

最後のグループでは不足する映像を最終フレーム、音声を0で埋めます
実機はヘッダー由来の実フレーム数で終了するため、埋めた映像は再生しません

## 帯域とメモリー

`27 × 2048 × 5 = 276480` バイト毎秒です
2倍速CDのデータセクター150枚毎秒、307,200バイト毎秒に対して90%を使います
低位ワークRAMには8グループ、442,368バイトの循環バッファを確保します
最初に最大4グループを読み、再生中も次のグループを先読みします

VDP2のVRAMは次の配置です

| オフセット | 用途 |
| --- | --- |
| `0x00000` | 辞書A、32KiB |
| `0x20000` | 辞書B、32KiB |
| `0x40000` | パターン表A、16KiB |
| `0x44000` | パターン表B、16KiB |
| `0x7FFFE` | 背景色 |

パターン表は2ワード形式、64列のページに40列を配置します
非表示の辞書バンクはCPU用のアクセス周期にし、32KiBの辞書更新と表示の競合を減らします
垂直同期でパターン表と辞書のアクセス周期を切り替えます
一覧画面では同じVRAMをRGB555ビットマップとして使用します

音声はSCSPの2か所を交互に使い、次のPCMを書いてから再生を切り替えます
NTSCの表示周期に合わせ、SCSPのピッチは `0x73FA` に設定しています
サンプル境界ごとの切り替えによる短い継ぎ目は残るため、連続したステレオ音声には対応していません

ハードウェアの設定は [Sega VDP2マニュアル](https://www.infochunk.com/saturn/segahtml_en/hard/vdp2/hon/p15_30.htm) と [SCSPマニュアル](https://antime.kapsi.fi/sega/files/ST-077-R2-052594.pdf) を参照しています
