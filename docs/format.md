# SVT2形式

すべての数値はビッグエンディアンです
先頭は2048バイトのヘッダー、その後は55,296バイトの独立したグループです
1グループは12フレームと音声4410サンプルを持ち、CDの27セクターに一致します

## ファイルヘッダー

| オフセット | バイト数 | 値 |
| --- | --- | --- |
| 0 | 4 | ASCII `SVT2` |
| 4 | 4 | バージョン2 |
| 8 | 4 | 幅320 |
| 12 | 4 | 高さ224 |
| 16 | 4 | 実フレーム数 |
| 20 | 4 | グループ数 |
| 24 | 4 | 1グループ12フレーム |
| 28 | 4 | 1グループ27セクター |
| 32 | 4 | 音声サンプルレート22050 |
| 36 | 4 | 1グループ4410サンプル |
| 40 | 4 | 辞書384項目 |
| 44 | 4 | 音声オフセット46476 |

残りは0です
圧縮処理のリビジョンを別のキャッシュファイルに記録します
今回のリビジョンは4で、以前の変換キャッシュは自動で作り直します
SVT2のデータ配置とSH-2の復元処理は変更していません

## グループ

| オフセット | バイト数 | 内容 |
| --- | --- | --- |
| 0 | 12288 | 4×4 RGB555画像384枚 |
| 12288 | 48 | 12フレームの開始オフセット |
| 12336 | 可変、最大34140 | 各フレームの更新情報 |
| 更新情報の末尾 | 可変 | 音声開始位置までの0埋め |
| 46476 | 8820 | 符号付き16ビットのモノラルPCM |

辞書の各画像は32バイトで、上から下、左から右の順です
画素は `0x8000 | R | G<<5 | B<<10`、各成分は5ビットです
フレームの開始オフセットはグループ先頭を基準にします

各フレームは最初の140バイトで8×8セル1120個の更新有無を示します
セルは40列×28行、左上から順に並びます
各バイトの上位ビットから使い、1なら後続の5バイトを消費します
0なら直前フレームの画素を保持します
各グループの最初のフレームは全セルを必ず更新します

5バイトは上位4ビットが0、その下に9ビットの辞書番号4個を格納します
番号は左上、右上、左下、右下の4×4画素を指します
番号の上限は383です
SH-2は4個を組み合わせ、VDP2の8×8セルに復元します

1グループで更新できる8×8セルは最大6492個です
同じ映像が続くフレームでは画素を再利用し、動いた部分に容量を回します
各セルについて12フレーム全体を調べ、更新回数ごとに誤差が最小となる保持区間を動的計画法で求めます
容量を超える場合は全セルで更新回数を配分し、グループ全体の二乗誤差が最小となる組み合わせを選びます
これは各フレームに最も近い辞書番号を更新候補とした範囲での最適化です
フレーム自体を削除する方式ではありませんが、激しい動きでは一部の細部に遅れや劣化が出る場合があります

辞書学習はRGB555の二乗誤差を使い、似た色だけで初期辞書を埋めないよう遠い画像から初期値を選びます
初期学習後は12フレームに含まれる全53,760個の4×4画像を使って辞書を再調整します
同一画像は出現回数を重みにしてまとめ、全体を調べても学習量を抑えます
寄与の小さい辞書項目を誤差の大きい場所へ移す試行も行い、全体の誤差が減る場合だけ採用します
CDの帯域や実機の処理量を増やさず、PC側の変換時間を画質へ回しています
元動画と完全に同じ画質を保証する形式ではありません

最後のグループは不足する映像を最終フレーム、音声を0で埋めます
グループの途中は直前の復元結果が必要ですが、任意のグループ先頭から再開できます

## 帯域とメモリー

`27 × 2048 × 5 = 276480` バイト毎秒で、SVT1から増やしていません
2倍速CDの307,200バイト毎秒に対して90%を使います
高速ワークRAMには8グループ、442,368バイトの循環バッファを確保します
最初に最大4グループを読み、再生中も先読みします
CDのデータは32ビット用ポートからSCU DMAで直接取り込みます

高速ワークRAMに12KiBの辞書2組と143,360バイトの復元画面を置きます
次の辞書は2KiBずつ事前転送します
復元画面はVDP2へSCU DMAで転送し、画素が変わらなかったフレームは転送を省きます

| VRAMオフセット | 用途 |
| --- | --- |
| `0x00000` | 画面Aの8×8セル画素 |
| `0x30000` | 画面Aのパターン表 |
| `0x40000` | 画面Bの8×8セル画素 |
| `0x70000` | 画面Bのパターン表 |
| `0x7FFFE` | 背景色 |

画面ごとに表示用と転送用を交互に切り替えます
一覧画面は同じVRAMをRGB555ビットマップとして使います

## 音声の連続再生

SCSPのサウンドRAMに35,280サンプル、8グループ分の循環バッファを置きます
通常のグループ境界ではKEY_OFFとKEY_ONを実行しません
再生を続けたまま、先の音声を1KiBずつ補充します
ループ終端の補間用サンプルも先頭に合わせます

開始、シーク、一時停止からの再開だけ再生位置を設定し直します
再開するフレームのサンプル位置を循環バッファの先頭へ合わせるため、区間の先頭に戻りません
NTSCの表示周期に合わせたSCSPのピッチ設定は `0x73FA` です
音声は22,050Hz、16ビット、モノラルです

ハードウェアの設定は [VDP2マニュアル](https://www.infochunk.com/saturn/segahtml_en/hard/vdp2/hon/p15_30.htm)、[SCUマニュアル](https://antime.kapsi.fi/sega/files/ST-097-R5-072694.pdf)、[SCSPマニュアル](https://antime.kapsi.fi/sega/files/ST-077-R2-052594.pdf) を参照しています
